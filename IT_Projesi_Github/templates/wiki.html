IT Bilgi Bankası (Knowledge Base)

Exchange Server üzerinden yeni kullanıcı oluşturulur. İlgili gruba (Üretim, İK vb.) atanır ve geçici şifre iletilir. Sonrasında MFA (İki Adımlı Doğrulama) aktif edilir.

Statik IP havuzundan (192.168.1.50-70) boş bir IP seçilir. Yazıcı menüsünden IPv4 ayarlarına girilip IP sabitlenir. Print Server'a yeni port açılarak eklenir.

Kullanıcıya cihaz teslim edilmeden önce IT Asset Manager portalından zimmet kaydı açılır. PDF raporu çıktı alınarak ıslak imza attırılır ve İnsan Kaynakları departmanına gönderilir.
